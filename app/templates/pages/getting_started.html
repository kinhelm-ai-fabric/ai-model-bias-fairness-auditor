Getting Started

What Is This App? Prerequisites Prepare Your Data Run an Audit Generate a Report Next Steps
1

What Is This App?

The AI Model Bias & Fairness Auditor helps you detect and measure bias in machine learning model predictions. Upload your model's predictions alongside demographic data, and the tool computes industry-standard fairness metrics. An AI agent then analyzes the results and generates an audit report with findings and recommendations.

2

Prerequisites

  • A CSV file containing your model's predictions, ground-truth labels, and at least one protected attribute column (e.g., gender, race, age group).
  • Knowledge of which column is your protected attribute and what the favorable label value is (e.g., "1" for approved, "yes" for selected).
  • (Optional) A Kindo API key and agent ID for AI-powered report generation.
3

Prepare Your Data

Your CSV file should have at minimum these columns:

ColumnDescriptionExample
labelGround truth outcome1, 0
predictionModel's predicted outcome1, 0
protected attributeDemographic group columnMale, Female

Column names are configurable. The protected attribute column can have any name — you specify it when creating the audit.

4

Run an Audit

  1. Click New Audit in the navigation bar.
  2. Enter a name and description for your audit.
  3. Upload your CSV dataset.
  4. Enter the name of the protected attribute column.
  5. Enter the favorable label value (default is "1").
  6. Click Create Audit — the analysis runs immediately.

Results appear on the audit detail page with per-group and cross-group fairness metrics.

5

Generate an AI Report

After running the analysis, click Generate AI Report on the audit detail page. The Kindo AI agent analyzes your metrics and produces a report with:

  • An executive summary of findings
  • Severity-rated bias findings per metric
  • Actionable recommendations for mitigation
  • Regulatory compliance notes

If the Kindo agent is not configured, a placeholder report is generated with basic guidance.

6

Next Steps

  • Review the Audits page to manage your audits.
  • Experiment with different protected attributes on the same dataset.
  • Compare results across model versions to track fairness improvements.
  • Share audit reports with compliance teams and stakeholders.
